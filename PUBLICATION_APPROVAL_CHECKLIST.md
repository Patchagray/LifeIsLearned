# Before making anything public

- [ ] Owner explicitly approves the public repository and each book release.
- [ ] Verify each package's rights/permissions, including narration voices and embedded MP3 redistribution.
- [ ] Confirm no raw voice masters, API credentials, private scripts, research, personal data or unpublished drafts are included.
- [ ] Verify actual package IDs/revisions, checksums and file sizes.
- [ ] Verify public unauthenticated download and catalog parsing.
- [ ] Confirm no claim that public package contents are hidden or protected from extraction.
